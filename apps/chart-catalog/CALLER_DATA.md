# Using your own data

Pass `ChartData` to `ChartPreview` to chart your own data. Omit `data` to see the example’s sample data.

The table lists supported inputs and interactions for the examples shown. Available data formats and interactions vary by example.

| Group | Examples | Supported behavior |
| --- | --- | --- |
| Tooltips | All eleven variants | Accept categories, series, colors, nullable samples and custom callbacks. Empty input shows a no-data state. Missing categories use row labels or numbered positions. |
| Bar | All eleven variants | Accept categories, values and colors in grouped, stacked, horizontal, value-label, square, depth, linked and loading charts. Positive and negative bar values stack separately. Empty input shows a no-data state. |
| Line | All 41 variants, including Chart Data Table | Accept supplied data for lines, bands, projections, thresholds, range selection, brush, zoom, synchronization, tables, export and loading. Empty input shows a no-data state. Large Data places observations along a sample-index axis. |
| Area | Sixteen basic examples and the Forecast, Reference Band, Reference Range and Trend overlays | Accept categories and series or numeric `rows.value`. Scales adapt to the data, and charts use the supplied dates and nullable samples. |
| Choropleth | All nine variants | Pan, zoom, inspect countries and use marker controls with your country and marker rows. Pattern states come from supplied status values. |
| Treemap | All four variants | Drill into the hierarchy, navigate back and inspect with the keyboard or pointer. Supports loading and duplicate sibling labels. |
| Stream | All three variants | Default and Loading use D3 inside-out ordering and wiggle stacking. Expand shows proportions on a 100% scale. Names, colors, categories and missing-sample readouts come from your data. |
| Waffle and Marimekko | All four Waffle and all three Marimekko variants | Use your colors and values, with loading controls and pinned legend selection where available. |
| Density groups | `density-groups` | Legend activation isolates a group; activating it again restores all groups. Numeric axes adapt to caller coordinates. |
| Gantt | All four variants | Phase rows and bands, multiple dependencies, fractional or percentage progress and ISO dates. |
| Vector stations | `vector-field-stations` | Cartesian `x`/`y` stations use a kilometre grid and km/h readings. Geographic `lon`/`lat` rows use a map projection and m/s readings. |

Line Markers accepts event objects and emoji/title strings. See the [catalog usage guide](README.md) for examples.

## Input formats

- **Bar:** categories plus nullable numeric series, or `rows: [{ label: 'First', value: 12 }]`. Row `category`, `label`, `date` and `name` can supply category labels. Missing labels use numbered positions, including when rows are empty or shorter than the series. Explicit categories define the visible positions; an empty categories array remains empty. Non-finite samples are unavailable, and zero remains a valid sample. Scales normalize before subtraction and stacking so tiny and large finite inputs retain usable geometry. Caller readouts and totals use additional precision or scientific notation as needed. Supplied data does not inherit fixture series, labels or footer statistics.
- **Line:** categories plus nullable numeric series, or `rows: [{ label: 'First', value: 12 }]`. Explicit categories define the visible positions; shorter series are padded with missing samples and longer series are clipped. Otherwise row `category`, `label`, `date` or `name` supplies labels, with numbered positions as the fallback. Zero is valid; non-finite samples are unavailable. Missing observations show dashes and isolated finite samples remain visible. Empty categories or series show no data; all-null series retain their category structure without invented values. Scales and readouts preserve tiny, subnormal and large finite values. The fixed-scale variant deliberately retains its 0–120 domain. Supplied input never fills missing rows, names, statistics or values from the demo.
- **Line dates and ranges:** valid ISO categories take priority, followed by aligned ISO `rows.date`. Complete, strictly increasing dates use elapsed-time positions in line charts, brush and zoom controls, and tables. Partial, repeated or reversed dates retain category positions and available date readouts. Undated labels stay undated. In **Large Data**, ISO strings serve as labels. Spacing, zoom and min/max sampling use sample indices.
- **Line overlays:** band rows accept finite `low` and `high`; multiple-band rows use a property matching each series name, containing `{ low, high }`. Bollinger variants derive a ten-observation mean and two population standard deviations from ten complete consecutive samples. Projection uses explicit row `goal`, or `forecast` for Manual Projection; extra future rows are retained. Deadline variants use the first row with `deadline: true`; `highlight: true` marks explicit regions. Threshold uses supplied finite `rows.threshold`, without a demo threshold or unit fallback. Pass overlay metadata to show targets. Permanent Loading Placeholder stays muted and noninteractive. The Loading example includes a Loading/Ready control in its full preview.
- **Tooltips:** categories plus nullable numeric series, or `rows: [{ label: 'First', value: 12 }]`. Row `category`, `label` and `date` can provide labels when categories are omitted. Series-only inputs use numbered positions. Missing or non-finite samples remain unavailable. Scales include zero and adapt to supplied values, including tiny and large finite values. Readouts use additional precision or scientific notation as needed. Currency examples use USD. `renderTooltip` receives the raw current and previous values and pin state. The tooltip sizes to its content, which can extend beyond the plot.
- **Area overlays:** categories plus nullable numeric series, or `rows: [{ label: 'First', value: 12 }]`. Aligned row `date` or category dates accept valid ISO calendar dates and datetime strings. Strictly increasing complete timestamps use a continuous time axis; partial, repeated or reversed dates use category positions while retaining available date readouts. Forecast starts at the first row with `forecast: true`, with the previous sample as the seam; otherwise it uses the last four positions. Reference Band accepts the first finite row pair `referenceLow`/`referenceHigh` in either order, otherwise 180–240. Reference Range spans rows marked `highlight: true`; without flags it highlights supplied dates October 12–18, 2026 when present. Trend fits each series’ finite samples across the supplied domain. Empty input has no demo fallback.
- **Choropleth:** `rows: [{ country: 'Germany', value: 120 }]`. `label` can replace `country`; country names match the atlas exactly. Duplicate country values use the last valid value. Pattern rows can add `status: 'live' | 'beta' | 'not yet'`. Marker variants accept finite `lon` and `lat` within geographic bounds, optional `label`, `category` and `value`. Marker values default to 1 and are clamped to zero or above. Duplicate marker labels remain independently inspectable. Mercator marker positions cap projected latitude at ±85.051129 degrees while readouts retain the supplied geographic coordinates. Caller readouts use raw values without demo metric suffixes.
- **Treemap:** nested `rows: [{ name: 'Platform', children: [{ name: 'Compute', value: 72 }] }]`. `label` aliases `name`; node colors are optional. Numeric values retain the existing hierarchy parser's accepted formats. Duplicate sibling names are supported.
- **Waffle:** `rows: [{ name: 'North', value: 30, color: '#2563eb' }]`, with `label` as an alias. Alternatively use categories and the first numeric series. Values are nonnegative; missing/invalid numeric values contribute zero.
- **Marimekko and Stream:** categories plus numeric series with optional colors. Omitted categories use numbered positions. Marimekko treats missing values as zero; Stream uses zero for stacking and a dash in inspection. Expand normalizes the nonnegative column totals to 100%.
- **Density groups:** `rows: [{ x: 1.2, y: 15, group: 'North', label: 'Sample 1' }]`, or categories plus numeric series. Non-finite/missing coordinates are skipped. Matching series entries can supply group colors. Caller axes/readouts use numeric values without demo units.
- **Gantt:** rows with `name`, numeric day-offset `start`/`end`, optional `owner`/`team`, `color` and `milestone`. Existing `dependsOn` indices and fractional `progress` from 0 to 1 remain supported. Add `dependencies: [0, 1]`, or string references to rows' explicit `id` fields, for multiple dependencies. Use `progressPercent` for percentages from 0 to 100. A row with `kind: 'phase'` or `taskCount` represents a phase header; `phase` labels its band. ISO `YYYY-MM-DD` start/end strings use the earliest supplied date as the origin; malformed dates are marked unavailable. Numeric-only schedules retain their previous variant origin.
- **Vector stations:** `rows: [{ x: 4, y: 6, label: 'Harbor', speed: 9, direction: 245 }]`. Coordinates are kilometres and speed is km/h. `speedKmh`, `bearing` and `name` are aliases. Bearings normalize modulo 360. Existing geographic rows use `lon`/`lat` and m/s. Use one coordinate format per dataset.
