# Polar, flow and hierarchy examples

The library includes 116 examples from these families. They use a shared theme, React controls and demo data. Bklit UI's MIT-licensed gauge notch geometry and sunburst partition layout are included under `upstream/`.

The Treemap focus audit covers 48 same-engine reference/library profiles in Chrome, Firefox and WebKit, at 577 and 286 CSS px, in both palettes and at device scale 1. All 840 paired demo phases match, and 708 public caller phases pass focus, pointer/key restoration, blur/re-entry, nested inspection and data replacement checks, including duplicate labels and missing/zero data. Breadcrumb whitespace, tabular numeric glyphs and SVG overflow match the measured reference behavior.

The raster audit uses the live reference's exact font bytes, typography and backing color. A process-local native capture adapter avoids Playwright's stylesheet mutation; all 6,000 captures preserve their before/after keyframes, sampled times, opacity and bounds. Across 3,000 paired frames, 29,400 opacity checks, 88,200 fill/stroke checks, 40,800 computed label records and 2,592 outlines agree. Bounds differ by at most 0.00494 px, and 189,550 native fill/border samples differ by at most one RGB level. All 1,000 WebKit whole-SVG frame pairs, including 600 nested frames, meet the unchanged three-level RGB ceiling across 127,153,500 pixel pairs.

The strict whole-frame gate remains failed in Chrome: 4,979 of 127,153,500 pixels exceed three RGB levels, with a maximum difference of 25. Firefox retains 347 exceeding pixels from the same total, with a maximum of 14. The finite nested contexts are Platform, Machine Learning, node_modules, node_modules/@tanstack, Media and Backups, sampled at 0, 20, 40, 60, 90 and 120 ms plus an idle frame. Other branches, states and display densities, entrance/loading-exit raster, and portfolio entrance easing remain outside this qualification. The narrow tooltip inset is retained.

The live React reference and the library were compared in Chromium for the gauge and sunburst controls and quarter-hour clock navigation, plus the named features of 11 funnel, nine radar and nine Sankey examples. The library was also tested with caller-provided data in the pie and ring render callbacks. The remaining comparisons include cross-browser behavior, exact visual rendering and motion, and the full set of states.
